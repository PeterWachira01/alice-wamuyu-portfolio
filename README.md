# Alice Wanjiru Wamuyu — Portfolio

Responsive portfolio built with React, TypeScript, Vite and lucide-react.

## Requirements
- Node.js (LTS recommended)
- Visual Studio Code (recommended)

## Run locally
1. Extract this folder.
2. Open the `alice-wamuyu-portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:
   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build
```powershell
npm.cmd run build
```
The production-ready website is generated in `dist/`.

## Personalisation before publishing
- Confirm Alice is happy to publish her phone number, email and CV publicly.
- Verify education dates and credentials, particularly the Diploma in Insurance entry.
- Replace or remove `public/Alice-Wanjiru-Wamuyu-CV.pdf` if a newer CV is supplied.
- Add project case studies only when Alice has approved the content and can share it without disclosing confidential insurer, client or patient information.

## Deploy
Can be deployed to Vercel, Netlify, or GitHub Pages. For a Vercel/Netlify deployment, connect the repository and use `npm run build` as the build command and `dist` as the output directory.
